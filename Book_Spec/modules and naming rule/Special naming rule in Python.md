
### 💡 額外的「特殊命名」規則 (Python 特有)

除了樣式，Python 還利用「底線」的位置來賦予變數特殊含義：

1. **單底線開頭 (`_variable`)**：
    
    - **隱含意義**：這是一個「私有 (Private)」變數，僅限於模組或類別內部使用。雖然技術上還是可以從外部存取，但這是一種「紳士協定」，告訴別人：「沒事別動這個變數」。
        
2. **雙底線開頭 (`__variable`)**：
    
    - **隱含意義**：強制的私有化。Python 會觸發「名稱修飾 (Name Mangling)」，讓外部更難直接存取，避免子類別意外覆蓋到父類別的變數。
        
3. **雙底線開頭且結尾 (`__init__`)**：
    
    - **隱含意義**：**魔術方法 (Magic Methods)**。這是 Python 系統保留的特殊名稱，你自己命名變數時**絕對要避開**這種格式。

這部分是 Python 語言中非常精妙的設計。在許多語言（如 Java 或 C++）中，私有屬性是由編譯器強制執行的（關鍵字 `private`）；但在 Python 中，我們更傾向於「**大家都是成年人 (We are all consenting adults)**」的哲學。

底線的數量與位置，其實就是開發者之間的**密碼**。以下為你深入拆解這四種特殊用法：

---

### 1. 單底線開頭 `_variable` (內部使用 / 慣例私有)

這被稱為「弱內部使用標誌」。

- **它的本質**：這只是一個**視覺提醒**。
    
- **原則來由**：Python 之父認為強制鎖死屬性會限制開發的靈活性。因此，用一個底線告訴其他工程師：「這個變數是為了讓這個類別內部運作而設計的，如果你從外部直接修改它，可能會導致預期之外的錯誤。」
    
- **技術影響**：
    
    - 如果你在 `module.py` 定義了 `_my_func`，當別人在別處使用 `from module import *` 時，**這個函數不會被匯入**。
        
    - 但在類別實例中，你依然可以輕易地透過 `obj._variable` 存取它。
---

### 2. 雙底線開頭 `__variable` (名稱修飾 / Name Mangling)

這才是 Python 最接近「強制私有」的機制，它的目的是為了**防止繼承中的命名衝突**。

- **運作機制**：當 Python 看到雙底線開頭（且結尾最多只有一個底線）的成員時，它會偷偷把名稱改成 `_類別名__變數名`。
    
- **範例場景**：
    
    - 假設父類別有一個 `__update` 函數，子類別也寫了一個 `__update` 函數。
        
    - 如果沒有這層機制，子類別會意外蓋掉父類別的邏輯。
        
    - 有了修飾後，父類別的其實叫 `_Parent__update`，子類別叫 `_Child__update`，兩者相安無事。
        
- **誤區警告**：這**不是**為了加密資訊，如果你知道規則，依然可以用 `obj._ClassName__variable` 抓到它。它的核心用意是「避免意外」，而非「絕對安全」。
    

---

### 3. 雙底線開頭且結尾 `__init__` (魔術方法 / Dunder Methods)

這類方法被暱稱為 **Dunder** (Double Under)。

- **原則來由**：這些是 Python 的「掛鉤 (Hooks)」。Python 內部在執行特定動作時（例如加法、初始化、列印），會自動去尋找對應的雙底線方法。
    
- **常用範例**：
    
    - `__init__`: 初始化物件。
        
    - `__str__`: 當你執行 `print(obj)` 時，決定要顯示什麼文字。
        
    - `__add__`: 定義當兩個物件相加 (`+`) 時的行為。
        
- **避免作法**：**永遠不要自創這種格式的名稱**（例如 `__my_logic__`）。萬一未來 Python 官方更新時也用了同名的魔術方法，你的程式碼會立刻崩潰。
    

---

### 4. 其他你必須知道的底線用法 (補充)

除了你提到的三種，實戰中還有兩個非常重要的「底線規範」：

#### A. 單底線結尾 `variable_` (避開關鍵字)

- **使用場景**：當你想用的變數名稱剛好被 Python 佔用了（關鍵字）。
    
- **範例**：
    
    Python
    
    ```
    # 你想用 class 這個字當變數，但 class 是保留字
    class_ = "三年二班" 
    ```
    
- **原則**：這是 PEP 8 推薦的作法，讓你既能保留語意，又不會觸發語法錯誤。
    

#### B. 單獨一個底線 `_` (無關緊要 / 佔位符)

- **使用場景**：當語法上需要一個變數，但你**根本不在乎**它的內容時。
    
- **範例**：
    

Python

```
    # 我只想執行五次，不需要用到迴圈數字
    for _ in range(5):
        print("Hello")
        
    # 解包時忽略某些值
    name, _, email = ("Tom", "IgnoreMe", "tom@example.com")
    ```
