## 一、 Python 是去哪裡「找」東西的？ (Import Search Order)

這是一切問題的根源。不論你有沒有虛擬環境，Python 找東西的順序（`sys.path`）是固定的：

1. **當前目錄 (Current Directory)**：你目前正在執行的那個 `.py` 檔案所在的資料夾。
    
2. **內建模組 (Built-in Modules)**：如 `os`, `sys`, `time`。
    
3. **第三方套件路徑 (site-packages)**：這就是 **虛擬環境** 與 **系統預設環境** 的關鍵差異點。
    

### 虛擬環境 (venv) vs. 系統環境

- **系統環境**：套件裝在全域路徑（例如 `/usr/lib/python3...` 或 `C:\Python3...`）。
    
- **虛擬環境**：當你啟動虛擬環境時，Python 會悄悄地修改 `sys.path`，將其指向虛擬環境資料夾內的 `site-packages`。
    
- **結論**：如果你在虛擬環境內，Python 會**優先**看虛擬環境裡的套件，看完了才去系統目錄找。
